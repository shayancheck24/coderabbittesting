# coderabbittesting

Sandbox repository for trying [CodeRabbit](https://coderabbit.ai) on pull requests and commits.

## Purpose

Use this repo to validate CodeRabbit configuration, review tone, and workflow (comments, summaries, doc suggestions) without touching production code.

## How to test

1. Open a branch and change something small (this README, a new file, or a trivial script).
2. Open a pull request against the default branch.
3. Confirm CodeRabbit runs and that feedback matches what you expect.

## Notes

- Keep changes intentionally small so reviews stay easy to compare run to run.
- No application runtime or deploy pipeline is required here.
